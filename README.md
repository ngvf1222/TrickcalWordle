# 🧈 트릭컬 워들 (Trickcal Revive Wordle)

트릭컬 리바이브(Trickcal Revive) 속 137명의 사도 이름을 맞추는 한글 자모 워들 게임입니다.

---

## ✨ 핵심 기능 & 게임 모드

1. **난이도 3단계 모드**
   - **기본 모드 (권장)**: 6회 시도, 사도 도감 비제공 (순수 기억력/자모 추리 플레이).
   - **이지 모드 (입문)**: 6회 시도, 사도 도감 열람 가능, 실시간 자동완성 추천 칩 제공.
   - **하드 모드 (고수)**: **5회 시도**, 사도 도감 비제공 (긴장감 넘치는 매운맛).

2. **설정(⚙️) 기능**
   - **글자수 제한 (보드 가로 칸 수 조절)**:
     - `풀 (9자)`: 전체 137명 (컴퓨터 기본값)
     - `6자 (모바일 추천)`: 126명 (92% 포함, 타일이 큼직해져 모바일 가독성 극대화!)
     - `4자` (115명) / `3자` (112명)
   - **다크 모드 / 라이트 모드 전환**.

3. **한글 자모(초성·중성·종성) 단위 세부 판정**
   - 글자가 달라도 겹치는 자음이나 모음이 있으면 개별 타일 뱃지(`[ ㅂ 🟩 ] [ ㅓ ⬛ ]`)로 힌트 제공.

4. **치팅 방지 보안 시스템 (F12 무력화)**
   - `/api/daily`에서 정답 평문을 제거하고, 서버 측에서 판정 결과를 연산하여 승리 또는 게임 오버 전까지 정답 유출을 원천 차단.

5. **사도 일러스트 카드 & 통계**
   - 정답 성공 시 해당 사도의 공식 일러스트 노출.
   - Wordle 스타일 이모지 클립보드 복사 공유.

---

## 🚀 실행 방법

```bash
cd /home/ngvf/txt-wordle

# 개발 서버 실행 (기본 포트 3000)
npm run dev

# 프로덕션 빌드
npm run build
```
